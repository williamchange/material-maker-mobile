Touch Gestures
~~~~~~~~~~~~~~

While not an exhuaustive list, this shows the most
common touch gestures available in Material Maker for Android.

In general, most desktop inputs can be mapped to
touch inputs in the following manner:
+-------------------------------------------------------+----------------------------------------------------+
| :kbd:`Tap`                                            | LMB Click                                         |
+-------------------------------------------------------+----------------------------------------------------+
| :kbd:`Double Tap`                                     | LMB Double Click                                  |
+-------------------------------------------------------+----------------------------------------------------+
| :kbd:`Long Press`                                     | RMB Click                                          |
+-------------------------------------------------------+----------------------------------------------------+


General
+++++++
+-------------------------------------------------------+----------------------------------------------------+
| :kbd:`Back Button`                                    | Return / Close active dialog                       |
+-------------------------------------------------------+----------------------------------------------------+


Graph Editor
++++++++++++
+-------------------------------------------------------+----------------------------------------------------+
| :kbd:`Two-Finger drag`                                | Pan                                                |
+-------------------------------------------------------+----------------------------------------------------+
| :kbd:`Two-Finger Pinch` | `Double-Tap + Drag`         | Zoom in/out                                        |
+-------------------------------------------------------+----------------------------------------------------+
| :kbd:`Long Tap`                                       | Add node menu                                      |
+-------------------------------------------------------+----------------------------------------------------+
| :kbd:`One-Finger Drag`                                | Box selection                                      |
+-------------------------------------------------------+----------------------------------------------------+
| :kbd:`Double Tap`                                     | Enters subgraph/nodegroup, or exit/go up a level   |
|                                                       | in subgraph hierarchy when double-tapping in an    |
|                                                       | empty area.                                        |
+-------------------------------------------------------+----------------------------------------------------+
| :kbd:`Two-Finger Tap`                                 | Undo                                               |
+-------------------------------------------------------+----------------------------------------------------+
| :kbd:`Three-Finger Tap`                               | Redo                                               |
+-------------------------------------------------------+----------------------------------------------------+

Nodes
+++++
+-------------------------------------------------------+----------------------------------------------------+
| :kbd:`Long Tap`                                       | Open expression editor (float parameter)           |
+-------------------------------------------------------+----------------------------------------------------+
